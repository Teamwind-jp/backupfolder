# backupfolderVB

![backupfolder](http://teamwind.serveblog.net/github/backupfolder/img.jpg)

本プロジェクトは、vb.netによるWindows用簡易コピーツールです。  
コピー元フォルダをコピー先へ丸ごとコピーします。
c#版も公開しています。

最も単純なコピー処理なので、オプション等を容易に追加できます。  
例えば、  
・特定拡張子のみコピー 、 特定拡張子の除外コピー  
・コピー先の不要ファイル削除  
・処理したフォルダの履歴管理  
・バッチ処理  
・複数フォルダ一指定  
・ログ出力  
など  

カスタマイズ等のご要望がございましたらご連絡ください。  
  
処理内容は、  
1.リエントラントのフォルダコピー関数（CopyFolderFile）をバックスレッドで起動しています。  
2.コピーは、（System.IO.File.Copy）を使用しています。  
3.同名ファイルがある場合は、更新日が新しい場合のみ上書きコピーします。  
4.実行したフォルダは、iniファイルに記憶、次回起動時に引き継ぎます。履歴管理はしていません。  
5.処理したフォルダは、TreeViewに表示しています。  
以上です。  
  

# Requirement
Windows11上で書いています。  
Visual Studio 2026を使用しています。Version: 18.1.1    
  
  
# Usage
1.起動後、上図サンプル画面を参考に入力欄を設定してください。startボタンで開始します。  
　対象フォルダは、D&Dしてください。コピー先を新たに作成する場合は、手入力してください。
